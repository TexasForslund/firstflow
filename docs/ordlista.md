# Ordlista

Orden vi använder i Firstflow, så att samma sak alltid heter samma sak (Texas, 2026-10-31). Gäller all text som användaren ser: knappar, rubriker, hjälptexter, felmeddelanden och notiser. Kod skrivs fortfarande på engelska.

Står ett ord under **Inte** ska det bytas mot ordet till vänster.

## Personer

| Säg | Inte | Betyder |
| --- | --- | --- |
| Elev | student, deltagare | Den som gör APL. Även vuxenutbildningens elever. |
| Lärare | APL-lärare, mentor | Läraren som har klassen och eleverna. |
| Handledare | praktikhandledare, APL-handledare | Personen på företaget som har eleven. |
| Skoladministratör | admin, skoladmin | Rollen som lägger in personal, klasser och elever. I löptext går "skolans administratör" bra. |
| Rektor | skolledare | |
| SYV | studie- och yrkesvägledare | Förkortningen räcker, alla vet vad den betyder. |

## APL och platser

| Säg | Inte | Betyder |
| --- | --- | --- |
| APL | praktik, LIA | Arbetsplatsförlagt lärande. |
| Företag | arbetsplats, arbetsgivare | Organisationen där eleven gör APL, t.ex. Kramfors El & Data. |
| Praktikplats | placering, APL-plats | Elevens plats: företag, handledare och period tillsammans. |
| Period | | Från- och till-datum för praktikplatsen. |
| APL-dagar | APL-dagar per vecka | Veckodagarna klassen är på APL och checkar in, t.ex. mån–tors. |
| Redovisningsdagar | veckoredovisningsdagar | Dagarna eleven redovisar, bland APL-dagarna. |
| Inriktning | grupp, spår | En del av klassen, t.ex. Dator eller Programmering. |

## Närvaro

| Säg | Inte | Betyder |
| --- | --- | --- |
| Checka in, incheckning | check-in, stämpla in | Eleven säger att hen är på plats i dag. |
| Närvaro | frånvaro (som rubrik) | Hur många APL-dagar eleven var på plats. |
| Bekräfta | godkänna, attestera | Handledaren säger att eleven var på plats. |
| Inte på plats | frånvarande | Handledarens svar när eleven inte var där. |

## Redovisningar

| Säg | Inte | Betyder |
| --- | --- | --- |
| Redovisning | veckoredovisning, rapport, logg | Elevens svar på klassens frågor en redovisningsdag. Läraren och handledaren säger alltid redovisning. |
| Fråga, följdfråga | | En följdfråga kommer direkt efter en fråga, t.ex. "Vad gjorde du?" efter "Ja". |
| Frågor | formulär, enkät | Klassens frågor i fliken Frågor. |
| Mall | frågemall | Sparade frågor att börja från. |
| Kommentar | svar, chatt | Under en redovisning. |
| Privat kommentar | intern kommentar | En kommentar som bara lärare och handledare ser ("Bara lärare och handledare"). |
| Anteckning | omdöme, bedömning | Handledarens anteckning om eleven i helhet: Beröm, Oro eller Övrigt. |

**Att bestämma:** eleven ser i dag "Dina inlägg" och "Se ditt inlägg" i sitt flöde, som i sociala medier. Ska eleven också se "redovisning"?

## Projekt och mål

| Säg | Inte | Betyder |
| --- | --- | --- |
| Projekt | uppdrag, uppgift | En uppgift som en eller flera elever gör, ofta på ett företag. |
| Mål | tagg, kompetens, kunskapskrav | Något eleven ska visa, t.ex. Kundkontakt. Gemensamt för skolan och kan pekas mot läroplanen. |
| Underlag | bevis, poäng | Elevens svar som visar ett mål. |
| Läroplanen | kursplanen, ämnesplanen | Skolverkets läroplan. Den exakta delen står vid målet, t.ex. "Elteknik, nivå 1". |
